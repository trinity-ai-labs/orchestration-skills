# The seat-load manifest: what each seat has open at each step, read by
# scripts/check.sh check 19, which sums each listed file's words over it and
# holds every step's load to the bound recorded here. A word is a run of
# non-whitespace in the file read as UTF-8, counted in Python, so a bound reads
# the same on every platform; `wc -w` does not, and is not this count.
#
# Four kinds of line, whitespace-separated, `#` to end of line a comment:
#
#   root   <seat> <path>
#       The file the seat's route starts from: its spine, or for a dispatched
#       reader the pass whose brief it is handed. It needs no namer, and it is
#       counted only where an `open` line lists it.
#   modes  <seat> <mode> [<mode> ...]
#       The modes the seat runs in; every one is measured separately.
#   open   <seat> <mode>[,<mode>...]|* <step> <path> [<path> ...]
#       The files the seat opens at that step, in that mode, in reading order.
#       Steps run in the order they first appear for the seat. A file stays
#       open once read, so a step's load is everything opened at it and at
#       every earlier step of the same mode.
#   bound  <seat> <mode> <step> <words>
#       The recorded load for that step in that mode. It is a RATCHET: a load
#       above its bound fails, and so does one below it, so a change that
#       shrinks a load lowers its bound here in the same PR.
#
# Every opened file must be NAMED (its repo path, verbatim) by the root or by a
# file the seat opened before it in that mode, so this file cannot route a seat
# to a file its prose never sends it to. Read the routing from the spine, not
# from this file.
